# Margoo Brand — landing page

Landing page da Margoo Brand, boutique feminina na Beira-Mar de Fortaleza. Projeto da DataCode Studio.

> Em construção. O README completo (stack, desafios técnicos, GIF e link do deploy) entra na Fase 5.

## Como rodar

```bash
npm install
npm run dev      # http://localhost:5173
npm run test     # Vitest
npm run lint     # ESLint
npm run build    # tsc + vite build
npm run images   # regenera public/img/ a partir de referencia/
```

## Pendências

- **Fotos provisórias**: as imagens atuais são capturas de tela da loja online. Antes de virar site oficial, trocar pelos originais das sessões de fotos (em `referencia/img*`) e rodar `npm run images`.
- **WhatsApp das consultoras** (Margarida e Edna): números pendentes. Ficam como `phone: null` em `src/data/content.ts`; o site mostra "[NÚMERO]".
